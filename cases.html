슬랙에 AI를 앱으로 걸어 두는 방식

실제 워크스페이스에 AI를 슬랙 앱으로 붙인 예시입니다. 채널에서 요청하면 앱이 읽고, 필요하면 생성·수정까지 이어 갑니다.

아래 화면은 Notion PPT 포맷을 학습하게 시킨 뒤, 같은 구조·스타일로 피티 자료를 만들도록 지시하는 대화입니다. 앱이 도구를 돌리며 대기·작업 상태를 스스로 남깁니다.

실시간 버튜버 카메라 트래킹 강의 활용

버튜버 프로그램을 직접 만들어서 사용하는 강의

실제 강의에서도 퀄리티가 보장된 애니메이션이 가미된 슬라이드와 더불어 카메라를 통해 얼굴과 손가락과 팔동작을 실시간으로 움직이는 커스터마이징한 버튜버를 만들어서 강의하며 흥미를 일으킵니다.

가이드 · 함께 만들기 내부 툴 전환 영상형 카드뉴스

영상형 카드뉴스 스튜디오 — 스스로 짜고, 내부 툴로 쓰기

마케팅·교육용 세로 영상 카드뉴스를 브라우저에서 편집·내보내기하는 스튜디오를, 처음부터 같이 설계·구현할 수 있도록 가이드합니다. “납품만 받고 끝”이 아니라, 팀 안에서도 이어서 고칠 수 있게 구조를 열어 둡니다.

가이드 이후에는 같은 프로그램을 사내·팀 내부 툴로 바로 붙입니다. 사진·문구·강조 효과·등장 타이밍을 맞춘 뒤 MP4 등으로 받아, 카드뉴스 제작 루프를 외부 툴 의존 없이 돌릴 수 있습니다.

우측은 실제 스튜디오 화면 기록입니다. 미리보기·효과 루프·파트별/전체 다운로드 흐름을 보여 줍니다.

주부 · 생활 비서 Oracle Cloud 무료 Telegram
